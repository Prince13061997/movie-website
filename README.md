# Movie App 🎬

A React app for browsing and saving favorite movies using TMDB API.

## Features
- Browse popular movies
- Search functionality
- Add/remove favorites
- Responsive design

## Setup
1. Clone repo:
   ```bash
   git clone[https://github.com/Prince13061997/movie-website]
Install dependencies:
npm install

Add TMDB API key to .env:
VITE_TMDB_API_KEY=your_key_here

Run app:
npm run dev

Tech Stack:-
React
React Router
Context API
TMDB API
CSS Modules
